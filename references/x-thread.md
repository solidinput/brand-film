# The "how we made it" thread

Video posts on X get far more reach than text, so post 1 carries the MP4 and the hook. The rest is short, concrete and true. Use only facts from this run (render time, length, line counts, what the checks caught).

## Shape

1. **Hook + video.** One funny sentence about what the character did, then the method in one line: "No After Effects. No Blender. Claude Code wrote it as HTML, HyperFrames rendered it to MP4 on a MacBook in <N> seconds. How it's made 🧵"
2. **The character is real.** It is the brand's own favicon or logo, turned into the site's style (pixels, same fonts, same signature details).
3. **Every frame is a function of time.** Hops are parabolas, landings a damped squash; seek to any frame and get the same picture.
4. **Every hop changes the screen.** On the beat at 120 BPM; a jump that changes nothing is cut. Name 2-3 of the best moments.
5. **Sound without samples.** Lines of Python, chiptune waves, every effect on its frame.
6. **The checks caught things.** Name the real misses the stills caught and how they were fixed.
7. Optional: credit the inspiration, and invite replies ("which logo should build its site next?").

## The Solidinput thread (2026-11-20)

> 1/ Our favicon got bored, so it built the website.
> No After Effects. No Blender. Claude Code wrote it as HTML, HyperFrames rendered it to MP4 on a MacBook in 12 seconds. How it's made 🧵
>
> 2/ The "S" is the real favicon. Claude turned the SVG path into 8px squares so it matches the site: same Bitcount pixel font, same dither seam, same pixel skyline of Tallinn.
>
> 3/ Every frame is a pure function of time. Hops are parabolas, landings are a damped squash. Jump to any frame and you get the same picture, which is what lets HyperFrames render it frame by frame.
>
> 4/ Every hop lands on a beat at 120 BPM and changes the page. A jump that changes nothing gets cut.
>
> 5/ The sound has no samples: ~200 lines of Python and numpy, chiptune pulse and triangle waves, each effect on its frame.
>
> 6/ Before the render: lint, layout and contrast checks, then stills of the key moments. The stills caught two misses: the S vanished on orange (it now gets an outline after the joke) and the end line needed an arrow.

## The Reels caption

Three short lines and the link, no thread. Line 1 retells the joke in plain words; line 2 says what the product does for the viewer; line 3 is the end line and the domain. Then 4-6 hashtags in the audience's language. Example (Din Firmaadresse, 2026-11-21):

> Our logo logged in, sorted the post and paid the invoice. Then it went back to its tab.
>
> Din Firmaadresse: a legal business address for your CVR, with your post scanned and in one dashboard from day one.
>
> Your post, handled. → dinfirmaadresse.dk

If the film has effects-only sound, remind the user to add a library track in the Reels editor.
